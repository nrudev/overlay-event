# Windows 설치 가이드 (Node.js + YouTube API 키)

이 프로그램을 Windows에서 실행하기 위해 필요한 두 가지, **Node.js 설치**와 **YouTube Data API 키 발급** 방법입니다.

## 1. Node.js 설치

1. [nodejs.org](https://nodejs.org/) 접속. Get Node.js 클릭

2. Node.js 다운로드 페이지 아래쪽에 Windows 설치 프로그램(.msi) 버튼 클릭하여 다운로드

3. 다운로드한 `.msi` 파일을 더블클릭해 설치 마법사 실행 → 전부 기본값("Next")으로 진행 → 설치 완료.
   - 중간에 "Automatically install the necessary tools" 체크박스가 나오면 체크 안 해도 됩니다 (이 프로젝트에는 필요 없음).

4. 설치가 끝나면 **새로운** PowerShell 또는 명령 프롬프트(cmd) 창을 열고 다음을 입력해 정상 설치를 확인합니다.

   ```bash
   node -v
   npm -v
   ```

   각각 버전 번호(예: `v24.x.x`, `10.x.x`)가 출력되면 성공입니다. "명령을 찾을 수 없습니다" 같은 오류가 나오면 PC를 재시작한 뒤 다시 시도하세요 (환경변수 PATH가 갱신되어야 함).
   오류 문구 안 뜨고 숫자만 제대로 나오면 문제 없음. 위에 24, 10 이런건 다 예시니까 참고.

## 2. YouTube Data API 키 발급

1. [Google Cloud Console](https://console.cloud.google.com/)에 구글 계정으로 로그인.
2. 화면 상단의 프로젝트 선택 드롭다운 클릭 → **"새 프로젝트"** 클릭 → 이름 입력(예: `overlay-event`) → **만들기**.
3. 좌측 메뉴(☰) → **"API 및 서비스" → "라이브러리"** 이동 → 검색창에 `YouTube Data API v3` 입력 → 검색 결과 클릭 → **"사용"** 버튼 클릭.
4. 좌측 메뉴 → **"API 및 서비스" → "사용자 인증 정보"** 이동 → 상단 **"+ 사용자 인증 정보 만들기"** → **"API 키"** 선택.
5. 키가 즉시 생성되어 화면에 표시됩니다. **복사**해서 안전한 곳에 보관하세요.
6. (권장) 방금 만든 키 목록에서 편집(연필 아이콘) 클릭 → **"API 제한사항"**에서 **"키 제한"** 선택 → `YouTube Data API v3`만 체크 → **저장**. (키가 유출되어도 다른 API에는 못 쓰게 막는 안전장치입니다.)

## 3. 프로젝트 실행하기 (파일 편집 없음)

아래 순서로 실행하면 됩니다.

1. 프로젝트 폴더(`overlay-event`) 안의 **`start.bat`** 파일을 더블클릭합니다.
   - 검은 창(명령 프롬프트)이 뜨고 처음 실행할 때는 필요한 파일을 자동으로 설치하느라 몇 분 걸릴 수 있습니다. 창을 닫지 말고 기다리세요.
   - Windows에서 "알 수 없는 게시자" 경고가 뜨면 "추가 정보" → "실행"을 눌러 진행하세요.
2. `대시보드: http://localhost:5175` 메시지가 보이면 정상 실행된 것입니다.
3. 브라우저(크롬/엣지 등)에서 `http://localhost:5175` 주소로 접속합니다.
4. 대시보드 맨 위 **"0. YouTube API 키 설정"** 칸에, 위 2단계에서 발급받은 키를 붙여넣고 **저장** 버튼을 누릅니다.
   - 파일을 열거나 이름을 바꿀 필요 없이, 이 화면에 붙여넣기만 하면 프로그램이 알아서 저장해서 다음에 실행할 때도 기억합니다.
5. 프로그램을 끝내려면 검은 명령 프롬프트 창을 닫으면 됩니다. 다음에 다시 쓸 때는 `start.bat`만 더블클릭하면 저장해둔 API 키가 그대로 남아있습니다.

> 참고: `start.bat`을 쓰지 않고 PowerShell에 직접 명령어를 입력해도 됩니다 (`npm install` → `npx playwright install chromium` → `npm run dev`). 개발자용 대안일 뿐 결과는 동일합니다.
