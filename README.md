# 라이브 채팅 키워드 추첨 → 마블 룰렛 연동

유튜브 라이브 채팅에서 지정한 시간 동안 특정 단어를 입력한 시청자를 중복 없이 모아
[Marble Roulette](https://lazygyu.github.io/roulette/)에 붙여넣을 수 있는 형식으로 정리해주는 도구입니다.

> `develop` 브랜치: 로그인/회원가입 없이 **여러 사용자가 하나의 서버를 동시에** 쓸 수 있도록 만든 버전입니다.
> 각자 자기 PC에 설치해서 혼자 쓰는 로컬 버전(룰렛 자동 반영 포함)은 `main` 브랜치를 참고하세요.

## 여러 사용자가 함께 쓰는 구조

- 로그인 계정이 없으므로, 브라우저를 열면 자동으로 임의의 **세션 ID**가 하나 생성되어 `localStorage`에 저장됩니다.
  이후 모든 요청에 이 ID를 실어 보내서, 서버는 같은 브라우저에서 온 요청만 같은 수집 상태로 묶어서 처리합니다.
  다른 사람이 접속해도 서로의 수집 명단·키워드·연결된 방송이 섞이지 않습니다.
- **YouTube API 키는 서버에 저장되지 않습니다.** 대시보드에 입력하면 이 브라우저의 `localStorage`에만 저장되고,
  요청을 보낼 때마다 함께 전송되어 그 순간에만 사용됩니다. 각자 자기 키의 할당량만 쓰게 되므로 동시 사용자가
  늘어도 한 키의 쿼터를 나눠 쓰다 고갈되는 문제가 없습니다.
- 서버는 3시간 이상 아무 요청도 없었던 세션을 주기적으로 정리합니다.
- 이 버전은 **룰렛 페이지에 자동으로 명단을 주입하지 않습니다.** (여러 사용자가 동시에 쓰면 사용자 수만큼
  서버에서 브라우저를 띄워야 해서 비용·리소스 부담이 커지기 때문) 대신 룰렛 입력창에 그대로 붙여넣을 수 있는
  형식(쉼표 구분, 동명이인은 `이름*횟수`)으로 명단을 보여주고, "명단 복사" / "룰렛 페이지 열기" 버튼으로
  사용자가 직접 마지막 한 단계만 진행합니다.

## 1. YouTube Data API 키 발급 (사용자가 각자 준비)

1. [Google Cloud Console](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다.
2. "API 및 서비스 → 라이브러리"에서 **YouTube Data API v3**를 검색해 활성화합니다.
3. "API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키"로 키를 발급받습니다.
4. (권장) 발급된 키를 편집해서 "애플리케이션 제한사항"을 설정해 두세요.

## 2. 서버 설치 및 실행

```bash
npm install
npm run dev
```

`PORT` 환경변수로 포트를 바꿀 수 있습니다(기본 5175). 예: `PORT=3000 npm run dev`

브라우저에서 서버 주소(예: `http://localhost:5175`, 또는 실제로 배포한 도메인)로 접속합니다.

## 3. 사용 방법

0. **API 키 저장**: 각자 발급받은 키를 대시보드 상단 칸에 붙여넣고 저장 (이 브라우저에만 저장, 최초 1회).
1. **라이브 연결**: 진행 중인 유튜브 라이브 방송의 watch URL(또는 videoId)을 입력하고 "연결".
   - 방송이 실제로 라이브 중이고 채팅이 켜져 있어야 합니다.
2. **수집 설정**: 키워드와 매칭 방식(정확히 일치 / 포함), 필요하면 수집 시간(분/초)을 입력 후 "수집 시작".
   - 시간을 비워두면 "수집 종료" 버튼을 누를 때까지 계속 수집합니다.
3. 채팅에 키워드를 입력한 시청자가 실시간으로 "실시간 현황"에 쌓입니다 (같은 계정 중복 입력은 1명으로 처리).
4. 필요하면 "자동 바이인"에 별도로 참가시킬 이름을 쉼표(,)로 구분해 입력하고 "추가" (자동 수집 명단과 합쳐지고, 리셋해도 유지됩니다).
5. "룰렛 연동"에서 최종 명단을 룰렛 입력 형식 그대로 확인하고, "명단 복사" → "룰렛 페이지 열기"로 새 탭에서
   Marble Roulette을 열어 입력창에 붙여넣고 시작하세요.
6. 다음 라운드를 진행하려면 "리셋" 후 2번부터 반복합니다 (자동 바이인 명단은 리셋해도 유지됩니다).

## 참고 / 제약사항

- YouTube API는 공개 라이브 방송의 채팅을 API 키만으로 읽을 수 있습니다(OAuth 불필요). 비공개/멤버십
  전용 채팅 등은 지원하지 않습니다.
- 폴링 간격은 YouTube API가 응답으로 알려주는 `pollingIntervalMillis`를 그대로 따릅니다.
- 세션 ID는 브라우저 `localStorage` 기준이므로, 같은 사람이라도 시크릿 창이나 다른 브라우저로 접속하면
  별도 세션으로 취급됩니다. 반대로 `localStorage`를 지우면 진행 중이던 수집 상태를 다시 불러올 수 없습니다
  (서버에는 여전히 남아있지만 새 세션 ID로는 접근할 수 없음).
- 수집 종료 알람음(`public/sounds/alarm.mp3`)은 Pixabay의
  ["Bedside clock alarm"](https://pixabay.com/sound-effects/household-bedside-clock-alarm-95792/)을
  Pixabay Content License(출처 표시 불필요, 자유 이용)에 따라 앞부분 3초만 잘라 사용했습니다.

## 로직만 빠르게 검증하기 (라이브 방송 없이)

```bash
npm run test:collector
```

가짜 채팅 메시지로 키워드 매칭과 계정 중복 제거 로직을 확인합니다.
