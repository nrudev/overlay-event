# 라이브 채팅 키워드 추첨 → 마블 룰렛 연동

유튜브 라이브 채팅에서 지정한 시간 동안 특정 단어를 입력한 시청자를 중복 없이 모아
[Marble Roulette](https://lazygyu.github.io/roulette/)에 자동으로 올려주는 로컬 도구입니다.

> Windows에서 Node.js 설치부터 시작한다면 [SETUP_WINDOWS.md](SETUP_WINDOWS.md)를 참고하세요.

## 1. YouTube Data API 키 발급

1. [Google Cloud Console](https://console.cloud.google.com/)에서 새 프로젝트를 만듭니다.
2. "API 및 서비스 → 라이브러리"에서 **YouTube Data API v3**를 검색해 활성화합니다.
3. "API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키"로 키를 발급받습니다.
4. (권장) 발급된 키를 편집해서 "애플리케이션 제한사항"을 IP 주소 등으로 제한해 두세요.

## 2. 설치 및 실행

```bash
npm install
npx playwright install chromium
npm run dev
```

브라우저에서 `http://localhost:5175` 접속. (Windows에서 터미널 없이 쓰고 싶다면 [SETUP_WINDOWS.md](SETUP_WINDOWS.md)의 `start.bat` 방식 참고)

API 키는 `.env` 파일을 직접 만들 필요 없이, 대시보드 맨 위 **"0. YouTube API 키 설정"** 칸에 붙여넣고 저장하면 됩니다.
서버가 자동으로 `.env` 파일에 저장해서 다음 실행 때도 기억합니다.

## 3. 사용 방법

0. **API 키 저장**: 위에서 발급받은 키를 붙여넣고 저장 (최초 1회만).
1. **라이브 연결**: 진행 중인 유튜브 라이브 방송의 watch URL(또는 videoId)을 입력하고 "연결".
   - 방송이 실제로 라이브 중이고 채팅이 켜져 있어야 합니다.
2. **수집 설정**: 키워드와 매칭 방식(정확히 일치 / 포함), 필요하면 수집 시간(초)을 입력 후 "수집 시작".
   - 시간을 비워두면 "수집 종료" 버튼을 누를 때까지 계속 수집합니다.
3. 채팅에 키워드를 입력한 시청자가 실시간으로 "실시간 현황"에 쌓입니다 (같은 계정 중복 입력은 1명으로 처리).
4. 필요하면 "자동 바이인"에 별도로 참가시킬 이름을 쉼표(,)로 구분해 입력하고 "추가" (자동 수집 명단과 합쳐지고, 리셋해도 유지됩니다).
5. "룰렛에 반영"을 누르면 Chromium 창이 새로 열리며 Marble Roulette 페이지에 최종 명단이 자동으로 채워집니다.
   - 이 창을 OBS의 "창 캡처" 또는 "브라우저 소스" 화면에 잡아 방송에 노출하면 됩니다.
6. 원하는 타이밍에 "룰렛 시작"을 눌러 추첨을 진행하세요 (룰렛 페이지에서 직접 시작 버튼을 눌러도 됩니다).
7. 다음 라운드를 진행하려면 "리셋" 후 2번부터 반복합니다.

## 참고 / 제약사항

- 룰렛 자동 반영은 Marble Roulette 페이지가 내부적으로 노출하는 `window.roulette.setMarbles()`라는
  **비공식 API**를 사용합니다. 해당 사이트가 크게 리뉴얼되면 자동 반영이 깨질 수 있으며, 이 경우에도
  화면에 표시되는 최종 명단을 수동으로 복사해 룰렛 페이지 입력창에 붙여넣는 방식은 항상 가능합니다.
- YouTube API는 공개 라이브 방송의 채팅을 API 키만으로 읽을 수 있습니다(OAuth 불필요). 비공개/멤버십
  전용 채팅 등은 지원하지 않습니다.
- 폴링 간격은 YouTube API가 응답으로 알려주는 `pollingIntervalMillis`를 그대로 따릅니다.

## 로직만 빠르게 검증하기 (라이브 방송 없이)

```bash
npm run test:collector
```

가짜 채팅 메시지로 키워드 매칭과 계정 중복 제거 로직을 확인합니다.
